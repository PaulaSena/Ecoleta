instalar o npm

npm init -y

criado o arqvo Json..

--------------------
{
  "name": "ecoleta",
  "version": "1.0.0",
  "description": "[https://paulasena.github.io/Ecoleta/]",

Instalar o express para criar os modulos
npm install express

//ligar o servidor
node serverjs

trocar em Json de test para start

"scripts": {

  },

> ecoleta@1.0.0 start

----
Configurar rotas e intalar o reestart do servidor com o nodemon

npm install nodemon --save-dev
npm install nodemon -D

----- ALTERANDO O SCRIPT DO Json DE 
  "scripts": {
    "start": "node src/server.js"
  },
 -- PARA
     "start": "nodemon src/server.js"

--reestart
> ecoleta@1.0.0 start
